# Controlled form preparation

AcroForm PDFs use their native named fields. DOCX templates use explicit
`{{placeholder}}` tokens. Flat PDFs and web/portal forms produce structured
worksheets; production never guesses coordinates or unknown field meanings.
Macros are not executed.

Mappings are proposed and approved separately. Approved current registry,
entity, license, case, and document metadata may fill fields. Missing or stale
answers create information requests. Restricted values remain encrypted and
masked in portal lists.

Registration pins an approved, active, available governed document version.
Inspection rechecks those exact bytes, and a reviewer must activate the
template before it can create an instance. Draft generation is a durable
`PREPARE_FORM` job; the worker retrieves the governed template, verifies its
SHA-256 digest, and stores the generated draft as a new governed document.

Generation always creates a draft copy and preserves the blank template. The
field snapshot and generated bytes are SHA-256 identified. Signature,
initials, and attestation fields are left blank and marked for a human.
Approval pins the exact draft hash; recording a signed governed document is a
separate action.

Milestone 6 does not log in to NMLS/state portals, insert signatures, attest,
pay fees, or submit. `SUBMITTED_EXTERNALLY` records a human action and reference
only.
